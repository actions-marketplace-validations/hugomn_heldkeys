# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good faith, keep criticism about the work, and do not harass anyone. Security research is welcome; attacking other contributors or their systems is not.

To report unacceptable behaviour, contact the maintainer privately at the address on [hugo.im](https://hugo.im), or through a private [security advisory](https://github.com/hugomn/heldkeys/security/advisories/new) if it involves a vulnerability. Reports are handled confidentially.
